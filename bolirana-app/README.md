# Proyecto: Bolirana Digital

Este es un proyecto full-stack que simula una bolirana digital.

## Estructura del Proyecto

Este repositorio es un monorepo que contiene tanto el frontend como el backend.

- **/frontend**: Contiene la aplicación de cara al usuario, construida con HTML, CSS y JavaScript.
- **/backend**: Contiene la API del servidor, construida con Python y FastAPI.
