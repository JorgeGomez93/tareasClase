# 📋 Lista de Contactos - React

## 🚀 Demo en Vivo

[Ver aplicación](https://tangerine-crepe-3d8d74.netlify.app/)

## 📖 Descripción

Aplicación React que muestra una lista de contactos con filtros, búsqueda y diseño responsive.

## 🛠️ Tecnologías

- React
- Vite
- CSS3
- Netlify

## ✨ Funcionalidades

- ✅ Lista de contactos
- ✅ Filtro por estado (activos/inactivos/todos)
- ✅ Búsqueda por nombre
- ✅ Orden alfabético
- ✅ Diseño responsive
- ✅ Avatares de placeholder
- ✅ Mensaje si no hay resultados

## 🏃‍♂️ Cómo ejecutar

```bash
npm install
npm run dev
```
